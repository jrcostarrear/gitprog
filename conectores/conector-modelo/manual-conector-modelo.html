Manual de uso do conector-modelo

Este HTML é o manual destinado aos programadores que irão consumir o conector depois que ele for instalado no SISC. Ao criar um conector real, substitua este conteúdo pelo manual específico do serviço integrado.

Identificação

  • Conector: conector-modelo
  • Destino SISC: conector__conector-modelo
  • Mensagem principal: conector-modelo.eco

Operação disponível

OperaçãoDescrição
ecoRetorna confirmação com o texto recebido. Serve como exemplo de contrato.

Payload esperado

{
  "operacao": "eco",
  "texto": "mensagem de validacao local"
}

Exemplo de mensagem SISC

{
  "_protocolo": {
    "origem": "sistema__operador",
    "destino": "conector__conector-modelo",
    "idmensagem": "conector-modelo.eco"
  },
  "payload": {
    "dados": {
      "operacao": "eco",
      "texto": "mensagem de validacao local"
    }
  }
}

Credenciais

O conector-modelo não exige credenciais reais. Conectores reais devem informar aqui quais arquivos secretos/*.json o operador deve criar no servidor, sem expor senhas no pacote.

Erros comuns

  • operacao invalida: envie operacao=eco.
  • campo texto e obrigatorio: envie texto como string não vazia.
